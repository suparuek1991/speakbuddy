# SpeakBuddy – วิธีติดตั้ง (ทำเหมือน TabiTalk)

1. GitHub → New repository ชื่อ `speakbuddy` (Public)
2. Add file → Upload files → ลากไฟล์ทั้งหมดในโฟลเดอร์ (index.html, manifest.json, sw.js, icon-*.png) → Commit
   ห้ามอัปโหลด README นี้ที่มี key / ห้ามใส่ API key ในไฟล์
3. Settings → Pages → Deploy from a branch → main / (root) → Save → รอ 1-2 นาที
4. เปิด https://suparuek1991.github.io/speakbuddy/ ด้วย Safari บน iPhone
5. กดแชร์ ⬆️ → เพิ่มไปยังหน้าจอโฮม
6. เปิดแอป → ⚙️ ตั้งค่า → วาง Gemini API key (ตัวเดียวกับ TabiTalk) → บันทึก & ทดสอบ
7. แท็บ 📚 เรียน → ด่าน 1 → แตะ 🎤 ครั้งแรก กดอนุญาตไมโครโฟน

ถ้าเสียงครูเบา/ไม่ออก: เช็กสวิตช์เงียบข้างเครื่อง
ถ้าเสียงอังกฤษแปลก: ตั้งค่า iPhone → การช่วยการเข้าถึง → เนื้อหาที่พูด → เสียง → English → ดาวน์โหลด Samantha / Ava (Enhanced)
